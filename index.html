Principles

Opinionated where it matters

Fifteen non-negotiable rules keep every component on the same grid — enforced by an automated QA gate, not by hoping.

Tokens only

No hardcoded colors, sizes, radii, shadows, or easings — everything reads CSS variables, so themes and palettes come for free.

WCAG AA, everywhere

Every text and UI pair is contrast-checked across light, dark, and all five palettes — automatically, on every change.

Flat elevation

No drop shadows — hairline borders carry depth. Fills are flat, corners are squircles, and one easing moves everything.

One type ramp

Twelve integer steps on a 14px base, set in Urbanist. Medium is the working weight; semibold is the ceiling.

Light by default

Every surface renders light unless the app explicitly opts into dark. Components never branch on theme — they only read tokens.

A QA gate, not a wiki

One script checks forbidden patterns, contrast, token drift, and compilation. Work is not done while it fails.

Quick start

Copy in, compose, ship

Formic is vendored, not installed — copy styles/ and the components you need, import one CSS stack, and compose. Two peer dependencies: React and Tabler icons.

globals.css · Tailwind v4
@import "tailwindcss";
@import "./tokens.css";          /* source of truth */
@import "./themes.css";          /* 5 palettes, optional */
@import "./tailwind-theme.css";  /* → text-ink, bg-hover, … */
App.tsx
import ChatThread from "./components/ChatThread";
import PromptBar from "./components/PromptBar";

export default function Chat() {
  return (
    <>
      <ChatThread messages={messages} />
      <PromptBar onSend={send} />
    </>
  );
}
