Principles

Opinionated where it matters

Five rules do most of the work. Every component follows them.

New component every week

The system grows with your product. Every week a new component ships, tested across light, dark, and all palettes, with AA contrast and the gates already passing.

Tokens only

No hardcoded colors, sizes, radii, shadows, or easings. Every component reads CSS variables, so themes and palettes come for free.

WCAG AA, everywhere

Every text and UI pair is contrast-checked across light, dark, and all five palettes, automatically, on every change.

One type ramp

Twelve integer steps on a 14px base, set in Urbanist. Medium is the working weight; semibold is the ceiling; bold never appears.

Quick start

One command, then your first prompt. The same command for a new project and an existing one; needs Node 20 or newer. The core is MIT and stays that way.

Build with your AI tool
  1. Install and run

    In the terminal, run npx formicai init --new my-app, then cd my-app && npm run dev; it scaffolds the app and the browser opens a page that says Formic is working.

    From the root of your Tailwind v4 app, run the command below. It does all of this for you and never overwrites your own files; npx formicai add <name> then adds one component and only what it needs, npx formicai doctor checks the setup, and npx formicai update refreshes Formic while keeping your edits:

    • puts the system into src/formic/: styles, the scripts behind the config and the two gates, and the base components; your AI tool adds each component as it needs it with npx formicai add <name> (or through the Formic MCP server the installer registers), and --all installs every one up front
    • writes src/formic/formic.config.json and applies it: accent, palette, radius, rail
    • adds the three CSS imports to your global stylesheet and installs the icon and avatar packages
    • writes the rules your AI tool reads: AGENTS.md, CLAUDE.md, .cursor/rules/, .github/copilot-instructions.md, .claude/skills/
    • adds npm run formic and a pre-commit hook so the gates run before every commit
    Terminal · inside your project folder
    npx formicai init && npm run dev

    The one thing it may ask of you: if it cannot find your global stylesheet, it says so, and you add these three lines yourself, in this order.

    src/index.css · only if the installer asks
    @import "./formic/styles/fonts.css";
@import "tailwindcss";
@import "./formic/styles/formic.css";

Questions

Short answers to what people ask before they run the command.

What is Formic?

Formic is an open-source React and Tailwind v4 design system built for AI coding tools. It ships 70+ token-driven components for chat, agents, dashboards and forms, passes WCAG AA contrast in light, dark and ten palettes, and includes two gates that refuse generic UI. It is MIT licensed.

Is Formic the ant colony simulation?

No. Formic AI Design System at formicai.dev is a React and Tailwind v4 component library for AI product interfaces, made by Eyosiyas Ketema, a product designer in Addis Ababa, Ethiopia. It is not related to any artificial life or ant colony simulation that shares the name; the only Formic here is components, tokens and the gates that check them.

Which AI coding tools does Formic work with?

Any agent that reads a project's AGENTS.md: Claude Code, Cursor, GitHub Copilot, OpenAI Codex, Gemini CLI, Windsurf and similar. The installer writes the rule files each tool looks for, and there is a Claude skill for Claude.ai.

How do I install Formic?

Run one command in your project folder: npx formicai init. Use npx formicai init --new my-app to start a new Vite project. It puts the base of the system into src/formic, writes the config, the agent rules and the MCP server entry, and prints your first prompt; after that npx formicai add <name> adds one component and only what it needs (the base is installed by default, --all installs every component), npx formicai docs <name> prints its props, and npx formicai doctor checks the setup. It needs Node 20 or newer.

How do I use Formic after installing it?

Start every prompt to your AI tool with: Use Formic (src/formic), read AGENTS.md, then ... and describe the screen you want. The agent composes it from Formic's components and runs the two gates before it finishes.

What are the two gates?

formic_check.py fails any UI that is not built on the system (a second component kit, hardcoded colours, an off-scale font size), and compose_check.py fails screens with no reason for what is on them (a stat card with no period, charts of unrelated things side by side, placeholder content). Both run on the app's own src folder, and the agent must pass them.

Can I use my own colours, font and layout?

Yes. The customizer at formicai.dev/customize sets the accent, palette, corner radius, font, type size, sidebar style and content width, then copies a block you paste to your AI tool. The accent is fitted to pass AA in both modes automatically.

Does Formic work in an existing project?

Yes, the same command adds it to an existing Vite, Next.js or other React project without touching your pages; you then add three CSS imports and prompt as usual.

Privacy

What happens with your data on this site: nothing, mostly.

Formic is a static website and an open-source library. It has no accounts and no tracking of its own. This page says what does and does not happen with your data when you visit formicai.dev.

What we do not collect

The site uses Vercel Web Analytics to count page views. It sets no cookies and stores no personal data: your IP address and browser details are turned into a short-lived hash so a visit is counted once, and the report we see is totals by page, country and referrer, never who you are. There is no advertising. The one form on the site is the Formic Pro waitlist: if you use it, your email address is stored (with the time you joined) so we can tell you, once, when Pro opens and what it costs. It reaches us as an email sent through Resend and may also be kept in a Vercel-managed Upstash database. It is not shared with anyone and not used for anything else. Email us to be removed.

What is stored in your browser

A few preferences live in your browser's local storage so the site remembers them: your light or dark choice and the choices you make in the customizer. They never leave your device and you can clear them at any time through your browser settings.

Third parties that see your request

Loading the site sends the usual requests to the services that serve it, each of which sees your IP address and browser details: Vercel (hosting; the waitlist is stored in a Vercel-managed Upstash database), Cloudflare cdnjs, jsDelivr and unpkg (script files), Google Fonts (the Urbanist typeface), Spline (the 3D scenes, loaded only when they scroll into view) and Unsplash (demo photographs). Buy Me a Coffee and GitHub are separate sites with their own policies; we link to them, nothing loads from them here.

The install script

npx formicai init runs on your own machine and only there. It downloads the component files from formicai.dev/r (a public, static registry) and writes them into the project folder you run it in. It sends nothing to us beyond the ordinary web requests for those files.

Security

How the site and installer are kept safe, and how to report a problem.

The site is static and stores no user data, which keeps the surface small. What we do to keep it that way, and how to tell us if something is wrong:

How the site is built

Every third-party script carries a Subresource Integrity hash and a pinned version, so a changed or tampered file on a CDN is refused by the browser. The check runs on every commit before the site can deploy. The site is served over HTTPS by Vercel with nosniff and referrer headers set.

The install script

The formicai command only ever reads the public registry and writes into your project folder. It requests no elevated permissions and never runs as root. It has no dependencies of its own, its source is published with the package, and npx formicai init --dry-run shows every file it would write before it writes anything.

Dependencies

The library depends on React, Tailwind and Phosphor icons. Dependabot watches the repository and security bumps are applied with the compiled files rebuilt in the same change.

Reporting a problem

If you find a vulnerability in the site, the installer or the library, email eyosiyasketema@gmail.com with the details and steps to reproduce. Please give us a reasonable time to fix it before publishing. We will reply and credit you if you want.
